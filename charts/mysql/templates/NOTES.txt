MySQL {{ .Chart.AppVersion }} 已部署（{{ include "mysql.fullname" . }} @ {{ .Release.Namespace }}）。

获取自动生成的 root 密码：
  kubectl -n {{ .Release.Namespace }} get secret {{ include "mysql.fullname" . }} -o jsonpath='{.data.MYSQL_ROOT_PASSWORD}' | base64 -d

连接（集群内）：
  kubectl -n {{ .Release.Namespace }} exec -it {{ include "mysql.fullname" . }}-0 -- mysql -uroot -p

备份：{{ if .Values.backup.enabled }}每天 {{ .Values.backup.schedule }}（{{ .Values.backup.timeZone }}）→ NFS {{ .Values.backup.nfs.server }}:{{ .Values.backup.nfs.path }}/mysql/，保留 {{ .Values.backup.retentionDays }} 天{{ else }}未启用{{ end }}

恢复（挂 NFS 的临时 Pod，mysql 客户端连 service）：
  LATEST=$(ls -1d /backup/mysql/*/ | sort | tail -1)
  mysql -h {{ include "mysql.fullname" . }} -uroot < "$LATEST/<db>.sql"
